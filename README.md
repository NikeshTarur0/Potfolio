## 🛠️ Tech Stack

- **Frontend Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Glassmorphism Dark Mode Palette
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Configuration**: Centralized configuration data inside `src/data/portfolioData.js`

---

## 🚀 Features

- 🐍 **Python-Inspired Theme**: Dark theme (`#0B0F17`) with Python blue (`#3776AB`) & gold/yellow (`#FFD43B`) accents.
- 💻 **Interactive Code Visual**: Animated terminal window running a FastAPI application snippet with syntax highlighting.
- 📄 **Dual Resume Selector Modal**: Supports 1-click download of both the **Python Developer Resume** and **.NET Developer Resume**.
- 📱 **Fully Responsive**: Optimized for Mobile (320px+), Tablet, Laptop, and Desktop viewports.
- 🎨 **Projects & Skills**: Showcases Multi-Vendor E-Commerce Backend, Indian Exam Document Processing Engine, Movie Booking System, and Bookstore Management System.

## 💻 Local Setup & Installation

```bash
# 1. Clone the repository
git clone https://github.com/NikeshTarur0/Potfolio.git

# 2. Navigate into project folder
cd Potfolio

# 3. Install dependencies
npm install

# 4. Run development server
npm run dev

# 5. Build for production
npm run build
```
